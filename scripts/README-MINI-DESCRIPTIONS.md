# Generate Mini Descriptions for All Products

This script automatically generates concise mini descriptions for all products in your Shopify store using AI.

## Features

- 🤖 **AI-Powered**: Uses OpenAI GPT to create engaging mini descriptions
- ✂️ **Smart Fallback**: If AI is unavailable, uses intelligent text extraction
- 📦 **Bulk Processing**: Processes all products automatically
- 💾 **Metafield Storage**: Saves to `custom.mini_description` metafield
- ⏭️ **Smart Skipping**: Skips products that already have mini descriptions

## Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Create Environment File

Create a `.env` file in the project root:

```bash
# Shopify API Credentials
SHOPIFY_STORE_URL=aa4383-53.myshopify.com
SHOPIFY_ACCESS_TOKEN=your_shopify_admin_api_token_here

# OpenAI API Key (Optional - for AI generation)
OPENAI_API_KEY=your_openai_api_key_here
```

### 3. Get Shopify Admin API Token

1. Go to your Shopify admin: `https://[your-store].myshopify.com/admin`
2. Navigate to **Settings** → **Apps and sales channels** → **Develop apps**
3. Click **Create an app**
4. Name it "Mini Description Generator"
5. Go to **API credentials** tab
6. Click **Configure Admin API scopes**
7. Enable these scopes:
   - `read_products`
   - `write_products`
8. Click **Save**
9. Click **Install app**
10. Copy the **Admin API access token**

### 4. Get OpenAI API Key (Optional)

If you want AI-powered descriptions:

1. Go to https://platform.openai.com/api-keys
2. Sign up or log in
3. Create a new API key
4. Copy the key to your `.env` file

**Note**: If you don't provide an OpenAI key, the script will use smart text extraction instead (first sentence or first 50 words).

## Usage

### Run the Script

```bash
npm run generate:mini-descriptions
```

Or directly:

```bash
node scripts/generate-mini-descriptions.js
```

### What It Does

1. ✅ Fetches all products from your Shopify store
2. ✅ For each product:
   - Checks if it already has a mini description (skips if yes)
   - Generates a new mini description using AI or smart extraction
   - Saves it to the `custom.mini_description` metafield
3. ✅ Shows progress and summary

## How Mini Descriptions Are Used

Once generated, the mini descriptions are automatically used on product pages:

1. **Priority Order**:
   - Custom mini description (entered in theme editor)
   - Product metafield `custom.mini_description` (generated by this script)
   - Auto-generated from full description (smart extraction)

2. **Display**:
   - Shows at the top of product pages (above the accordion)
   - Full description remains in the accordion section below

## Troubleshooting

### Error: SHOPIFY_ACCESS_TOKEN required

Make sure your `.env` file exists and contains the token.

### Error: HTTP 401 Unauthorized

Your Shopify API token is invalid or expired. Generate a new one.

### Error: HTTP 403 Forbidden

Your API token doesn't have the required permissions. Make sure you enabled:
- `read_products`
- `write_products`

### AI Generation Failing

If OpenAI API calls fail, the script will automatically fall back to smart text extraction. Check:
- Your OpenAI API key is valid
- You have credits in your OpenAI account
- Your internet connection is stable

### Rate Limiting

The script includes a 1-second delay between AI requests to avoid rate limiting. If you have many products, the script may take a while to complete.

## Notes

- The script **skips** products that already have mini descriptions
- Products without descriptions are skipped
- The script is safe to run multiple times (won't overwrite existing descriptions unless you modify the code)
- Mini descriptions are stored as metafields, so they persist across theme changes
