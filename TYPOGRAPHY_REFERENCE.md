# Typography Reference Guide
## Font Sizes to Check on Desktop and Mobile

### Default Values (in rem - multiply by 10px for pixel equivalent)
**Note**: Root font size is 10px, so 1rem = 10px

---

## 📐 DESKTOP FONT SIZES

### 1. **HEADINGS** (Section Titles)
- **Default**: `3.5rem` = **35px** (10px × 3.5)
- **Line Height**: `1.2`
- **Font Weight**: `700` (Bold)
- **Used in**:
  - `h1`, `h2` (all section headings)
  - `.homepage-section-heading`
  - `.vastu-heading`
  - `.faq-v3__title`
  - `.banner-v155__title`
  - All section titles

### 2. **CARD TITLES** (Product/Item Titles)
- **Default**: `1.5rem` = **15px** (10px × 1.5)
- **Line Height**: `1.3`
- **Font Weight**: `600` (Semi-bold)
- **Used in**:
  - `.vastu-product-card__title`
  - `.vastu-shop-by-concern__trigger-title` (Accordion titles)
  - `.vastu-shop-by-concern__product-title`
  - `.vastu-shop-by-concern__benefits-title`
  - `.vastu-shop-by-concern__recommended-title`
  - `.vastu-help-address-v1__text`
  - `.faq-v3__question` (FAQ accordion questions)
  - `.vastu-grid-card__title`
  - All product/item titles

### 3. **DESCRIPTIONS** (Content Text)
- **Default**: `1.6rem` = **16px** (10px × 1.6)
- **Line Height**: `1.5`
- **Font Weight**: `400` (Normal)
- **Used in**:
  - `.vastu-shop-by-concern__trigger-question` (Accordion questions)
  - `.vastu-shop-by-concern__card-description`
  - `.vastu-shop-by-concern__benefits-list li`
  - `.vastu-shop-by-concern__recommended-list li`
  - `.vastu-shop-by-concern__cta-link`
  - `.vastu-help-address-v1__description`
  - `.faq-v3__answer` (FAQ accordion answers)
  - All description/content text

### 4. **SUBTITLES**
- **Default**: `1.6rem` = **16px** (10px × 1.6)
- **Line Height**: `1.4`
- **Font Weight**: `400` (Normal)
- **Used in**:
  - `.banner-v155__subtitle`
  - All subtitle elements

### 5. **BODY TEXT** (Buttons, Inputs, General Text)
- **Default**: `1.6rem` = **16px** (10px × 1.6)
- **Line Height**: `1.5`
- **Font Weight**: `400` (Normal)
- **Used in**:
  - Buttons (`.xo-btn`, `button`)
  - Input fields
  - Footer content
  - General body text

### 6. **TAGS/BADGES**
- **Default**: `1.25rem` = **12.5px** (10px × 1.25)
- **Line Height**: `1.2`
- **Font Weight**: `600` (Semi-bold)
- **Used in**:
  - Product badges
  - Tags
  - Small labels

### 7. **PRICES**
- **Default**: Uses `--global-card-price-font-size-desktop` (typically `1.2rem` = **12px**)
- **Font Weight**: `700` (Bold)
- **Used in**:
  - Product prices
  - Price tags

## 📝 NOTES

- All font sizes are in **rem** units (relative to root font size, which is 10px)
- To convert rem to px: **rem × 10 = px**
- Example: 3.5rem = 35px (3.5 × 10)
- All typography is now controlled globally via theme settings
- Individual component CSS files no longer have font-size/line-height declarations
- Check these values match across all sections for consistency
